# دفتر کلاس

نسخهٔ آمادهٔ انتشار به‌صورت PWA و مناسب GitHub Pages.

نسخهٔ جاری **V21.1.0** است. برنامه دو فضای مستقل «معلم» و «مدیر» دارد. پنل مدیر از نقش‌های محدود به سازمان و شعبه، انتخاب سازمان فعال، ممیزی، مرکز اقدام، شاخص تازگی/کیفیت داده و فهرست سریع مدرس، کلاس و دانش‌آموز پشتیبانی می‌کند. اشتراک گزارش فقط با عضویت و رضایت صریح معلم فعال می‌شود و با خروج معلم، داده‌های مدیریتی مشتق‌شده به‌صورت تراکنشی پاک می‌شوند. یادداشت خصوصی، کتاب، Listening، عکس، تلفن و PIN وارد گزارش مدیر نمی‌شوند. ذخیره‌سازی حساس خطا را پنهان نمی‌کند، جایگزینی رسانه قابل بازگشت است و تغییر وضعیت رمزگذاری در برابر قطع ناگهانی دفتر بازیابی دارد. جزئیات امنیت، مهاجرت و محدودیت‌های صادقانه در راهنمای V21 آمده است.

این نسخه دارای هفت پالت مکمل برای شخصی‌سازی کل رابط کاربری است: کلاسیک، یاسی، هلویی، آسمانی، رز، مریم‌گلی و کره‌ای-آبی. پالت انتخابی در حالت روشن و تاریک حفظ می‌شود.

در نسخهٔ V6، روشنایی سطوح برای کاهش خستگی چشم متعادل و رنگ‌های اصلی کمی پررنگ‌تر شده‌اند تا رابط هم خواناتر باشد و هم بی‌روح به نظر نرسد.

نسخهٔ V7 قابلیت بازگردانی حذف‌ها، انتخاب تصادفی عادلانه بدون تکرار، حذف غایبان از قرعه، یادآوری‌های هوشمند و قفل اختیاری PIN/قفل دستگاه را اضافه می‌کند.

در نسخهٔ V8، تایپوگرافی فارسی، نیم‌فاصله‌ها، فاصلهٔ خطوط و متن‌های رابط بازنویسی شده‌اند. همچنین معلم می‌تواند رنگ دکمه‌های اصلی را مستقل از پالت کلی روی حالت خودکار، کهربایی، مرجانی، نعنایی، آبی، بنفش یا سرمه‌ای تنظیم کند.

در نسخهٔ V9، «رنگ و ظاهر» از تنظیمات عمومی جدا شده و با آیکون قلم‌مو باز می‌شود. علاوه بر پالت‌های آماده، معلم می‌تواند ۱۵ رنگ رابط را برای حالت روشن و تاریک جداگانه شخصی‌سازی کند؛ رنگ متن دکمه‌ها و وضعیت‌ها نیز برای حفظ خوانایی به‌صورت خودکار تنظیم می‌شود.

در نسخهٔ V10، هر کلاس بخش مستقل «کتاب درسی کلاس» دارد. معلم می‌تواند فایل PDF یا EPUB تا ۱۰۰ مگابایت را بارگذاری کند، آن را بدون اینترنت باز یا دانلود کند و در صورت نیاز کتاب را جایگزین یا از دستگاه حذف کند. نوع واقعی فایل پیش از ذخیره بررسی می‌شود و کتاب‌های حجیم جدا از داده‌های اصلی برنامه در IndexedDB نگهداری می‌شوند.

در نسخهٔ V11، طراحی کل برنامه بازپردازی شده است: هدر و نوار ناوبری شناور، کارت‌های کلاس و دانش‌آموز، فرم‌ها، مودال‌ها، تقویم، یادآوری‌ها، صفحهٔ پروفایل، حالت‌های خالی و بازخوردهای لمسی همگی از یک زبان بصری یکپارچه استفاده می‌کنند. فاصله‌ها، کنتراست، سایه‌ها و اندازهٔ ناحیهٔ لمس برای موبایل و دسکتاپ بهینه شده‌اند و تمام پالت‌ها و رنگ‌های سفارشی معلم همچنان روی طراحی جدید اعمال می‌شوند.

در نسخهٔ V12، داده‌ها و رسانه‌های محلی در صورت فعال‌کردن PIN با AES-256-GCM رمزگذاری می‌شوند. بکاپ ZIP شامل داده‌ها و تصویر پروفایل است؛ کتاب‌های درسی و فایل‌های شنیداری عمداً داخل بکاپ قرار نمی‌گیرند تا فایل خروجی سبک و قابل‌اعتماد بماند. کد برنامه به فایل‌های مستقل تقسیم شده، `unsafe-inline` از CSP حذف شده، فونت Vazirmatn داخل پروژه قرار گرفته و تست‌های خودکار برای CSP، ZIP، رمزگذاری، فایل‌های PWA و فونت اضافه شده‌اند. جست‌وجوی کلاس و دانش‌آموز، مدیریت فضای کتاب‌ها، کنترل کنتراست و گزارش Excel/PDF نیز در این نسخه موجود است.

در نسخهٔ V12.1، عنوان و توضیح گزینه‌های تنظیمات کاملاً از هم جدا شده‌اند، کادر کارت‌ها واضح‌تر است و عنوان هر گروه تنظیمات کادر مستقل و خواناتری دارد.

در نسخهٔ V12.2، مسیرهای تزریق HTML بسته شده‌اند، پیش‌نویس‌های حساس در حالت رمزگذاری دیگر به‌صورت متن ساده باقی نمی‌مانند، مهاجرت رمزگذاری کتاب‌ها قابل‌بازگشت شده و رابط تنظیمات، امنیت، رنگ‌ها، گزارش‌ها، اعلان‌ها و یادآوری‌های هوشمند در هر شش زبان پوشش یکسان دارد. دسترس‌پذیری مودال‌ها و صفحهٔ قفل نیز تقویت شده است.

در نسخهٔ V13، خروجی Excel به فایل واقعی `.xlsx` و گزارش به PDF مستقیم تبدیل شده است. ساخت ZIP بدون کپی‌کردن همهٔ کتاب‌ها در یک آرایهٔ بزرگ انجام می‌شود. سرویس اختیاری Node.js/PostgreSQL در پوشهٔ `server` همگام‌سازی سرتاسری رمزگذاری‌شده و Web Push واقعی را فراهم می‌کند؛ کتاب‌ها و عکس پروفایل هیچ‌گاه وارد همگام‌سازی ابری نمی‌شوند. تعارض ویرایش دو دستگاه نیز از داخل برنامه قابل‌حل است.

## اجرای تست‌ها

با Node.js نسخهٔ جدید، دستور `npm test` را اجرا کنید؛ این دستور ابتدا فایل‌های یتیم و مراجع خراب را با `npm run audit` بررسی می‌کند. برای آزمون مرورگری ابتدا `npm install` و سپس `npm run test:browser` را اجرا کنید. تست تصویری همهٔ پالت‌ها با `UPDATE_SNAPSHOTS=1 npm run test:visual` خط مبنا می‌سازد و اجراهای بعدی با `npm run test:visual` تغییرات ناخواسته را تشخیص می‌دهند. چک‌لیست آزمون روی گوشی واقعی در `tests/DEVICE-TEST-CHECKLIST.md` و توضیح لایه‌های کد در `ARCHITECTURE.md` قرار دارد.

## حریم خصوصی و مجوز

سیاست حریم خصوصی در `PRIVACY.md`، راهنمای گزارش آسیب‌پذیری در `SECURITY.md`، تغییرات نسخه‌ها در `CHANGELOG.md` و مجوز کد در `LICENSE` قرار دارد. فونت Vazirmatn تحت SIL Open Font License و فایل مجوز آن در `assets/fonts/OFL.txt` نگهداری می‌شود.

## انتشار

برای حالت فقط آفلاین، فایل‌های این پوشه را در ریشهٔ مخزن GitHub قرار دهید و GitHub Pages را فعال کنید. برای همگام‌سازی و Push، فایل `server/.env.example` را به `server/.env` تبدیل و مقادیر امن را وارد کنید، سپس سرویس را پشت HTTPS اجرا کنید. راهنمای کامل در `server/README.md` است.

## حریم خصوصی

به‌طور پیش‌فرض داده‌ها فقط روی دستگاه هستند. همگام‌سازی شخصی معلم سرتاسری رمزگذاری شده است. گزارش مدیریتی نیز اختیاری و با رضایت معلم است و در سرور با AES-256-GCM رمزگذاری می‌شود؛ کتاب، Listening، عکس، تلفن، PIN و یادداشت خصوصی روی دستگاه می‌مانند. مرتباً بکاپ ZIP بگیرید.

## نکتهٔ امنیتی

نسخهٔ ابری باید پشت HTTPS، با رمز پایگاه‌دادهٔ قوی، VAPID اختصاصی، مقدار تصادفی و ثابت `MANAGER_DATA_KEY` و بکاپ منظم PostgreSQL منتشر شود. رمز حساب و کلید مدیریتی باید در مدیر رمز نگهداری شوند.

## V15 enterprise manager additions
The manager portal now supports multi-branch administration, role-scoped management staff, paginated teacher/class discovery, one-use/time-limited join codes, operational branch metrics, system health and an audit trail. Teacher data sharing remains consent-based and can be fully revoked from the teacher app.

For an existing V14 backend, run `npm --prefix server run migrate` with `DATABASE_URL` configured before starting V15. For new installations, `server/schema.sql` remains the complete bootstrap schema.

For production deployments, keep PostgreSQL backups off the application disk as well. `server/scripts/backup.sh` verifies each dump and can mirror it to a mounted independent target using `BACKUP_MIRROR_DIR`.
